# Natural Language Processing Projects Overview

This repository contains assignments completed as part of the **Natural Language Processing (NLP)** course, focusing on core NLP concepts, language modeling, and neural network-based parsing.

---

## Assignments

### **Assignment 2: N-Gram Language Models**
- **Objective**: Build and evaluate unigram, bigram, and smoothed bigram models using the Brown Corpus.
- **Key Topics**:
  - Zipf's law and word frequency analysis
  - Maximum Likelihood Estimation (MLE) for unigram and bigram models
  - Add-α smoothing for handling data sparsity
  - Perplexity evaluation for language models
- **Outcome**:
  - Explored language modeling fundamentals and evaluated the performance of different models on a toy corpus.

### **Assignment 3: Build Your Own Language App**
- **Objective**: Develop a language web app using OpenAI's API to generate idioms and explanations for language learning.
- **Key Highlights**:
  - Created a simple, user-friendly app ("A Way with Words") for generating idioms based on user input.
  - Incorporated styling changes and functionality to make the app visually appealing.
  - Proposed enhancements such as DALL-E integration and interactive flashcards for a future version.

### **Assignment 4: Dependency Parsing**
- **Objective**: Implement a neural dependency parser using PyTorch to analyze grammatical structures.
- **Key Topics**:
  - Transition-based parsing (SHIFT, LEFT-ARC, RIGHT-ARC)
  - Neural network training and evaluation using UAS (Unlabeled Attachment Score)
  - Error analysis for different attachment types (prepositional, verb phrase, modifier, coordination)
- **Outcome**:
  - Trained and evaluated a parser, achieving high UAS scores and analyzing erroneous parses.
